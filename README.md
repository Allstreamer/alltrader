# All-Trader
A GUI for the V2 [Space-Traders](https://spacetraders.io/) API game
![image](https://github.com/Allstreamer/alltrader/assets/48365544/5a2bc4c0-4b9b-4904-b491-aae9ba26e405)



## Run
```bash
git clone https://github.com/Allstreamer/alltrader
cd alltrader
cargo run
```
